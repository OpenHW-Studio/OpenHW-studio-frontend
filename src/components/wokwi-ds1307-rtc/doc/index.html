DS1307 RTC Module

Real-Time Clock module with I2C interface (address 0x68). Keeps accurate time using a 32.768 kHz crystal and a CR2032 backup battery. Compatible with the RTClib library.

PCB Module

The DS1307 maintains date and time even when the Arduino is powered off, thanks to the CR2032 backup battery. It communicates over I2C using address 0x68 and stores all values in BCD format.

In OpenHW Studio, right-click the DS1307 during simulation to set the starting date and time. The clock advances in real time while the simulation runs.

► Try it in the Simulator

DS1307 wired to I2C (A4/A5). The sketch reads the current time every second and prints it to the Serial Monitor.

Example Code

Install the RTClib library before running.

#include <Wire.h>
#include <RTClib.h>

RTC_DS1307 rtc;

void setup() {
  Serial.begin(9600);
  Wire.begin();
  rtc.begin();
  if (!rtc.isrunning())
    rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
}

void loop() {
  DateTime now = rtc.now();
  Serial.print(now.hour());  Serial.print(':');
  Serial.print(now.minute()); Serial.print(':');
  Serial.println(now.second());
  delay(1000);
}
