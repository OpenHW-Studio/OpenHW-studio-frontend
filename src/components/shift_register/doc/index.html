74HC595 Shift Register

Logic

The 74HC595 is an 8-bit serial-in, parallel-out shift register. It allows you to control 8 digital outputs using only 3 Arduino pins (SER, SRCLK, RCLK). Multiple chips can be daisy-chained via Q7' to expand output count indefinitely.

Pins

PinLabelDescription
vccVCC5 V power supply
gndGNDGround
serDSSerial data input — connect to Arduino digital pin
srclkSHCPShift register clock — rising edge shifts in one bit from SER
rclkSTCPStorage register clock (latch) — rising edge copies SR → output
oe/OEOutput enable (active LOW) — tie to GND to enable outputs
srclr/SRCLRShift register clear (active LOW) — tie to VCC for normal operation
q0–q7Q0–Q78 parallel output pins
q7sQ7'Serial output for daisy-chaining to next chip's SER

Wiring

Arduino D11 ── SER   (DS)
Arduino D12 ── SRCLK (SHCP)
Arduino D8  ── RCLK  (STCP)
GND         ── /OE
5V          ── /SRCLR
VCC = 5V,  GND = GND

Example Code (shiftOut)

#define SER   11
#define SRCLK 12
#define RCLK  8

void setup() {
  pinMode(SER, OUTPUT);
  pinMode(SRCLK, OUTPUT);
  pinMode(RCLK, OUTPUT);
}

void writeRegister(byte data) {
  digitalWrite(RCLK, LOW);
  shiftOut(SER, SRCLK, MSBFIRST, data);
  digitalWrite(RCLK, HIGH);
}

void loop() {
  for (int i = 0; i < 8; i++) {
    writeRegister(1 << i);   // Light each output in sequence
    delay(200);
  }
}
Tip: Chain two 74HC595s by connecting Q7' of the first chip to SER of the second. Call shiftOut() twice before pulsing RCLK to control 16 outputs.
