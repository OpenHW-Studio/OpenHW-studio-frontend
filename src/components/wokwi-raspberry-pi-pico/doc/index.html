Raspberry Pi Pico

Boards

The Raspberry Pi Pico is based on the RP2040 microcontroller and is supported as a programmable board target in OpenHW Studio. This board profile defines GPIO and serial pin behavior so circuits can be developed in the same flow as Arduino Uno.

Specifications

PropertyValue
MCURP2040
GPIOGP0-GP28
UART defaultTX=GP0, RX=GP1
Power railsVBUS, VSYS, 3V3, GND
