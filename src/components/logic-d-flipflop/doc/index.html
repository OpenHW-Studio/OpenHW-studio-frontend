D Flip-Flop

Logic

A positive-edge-triggered D Flip-Flop. On the rising edge of CLK, the output Q captures the value of the data input D. The Qbar output is always the complement of Q.

Pins

PinTypeDescription
DDigitalData input
CLKDigitalClock input (rising-edge triggered)
QDigitalOutput — captures D on rising CLK edge
QbarDigitalInverted output — complement of Q

Wiring


Arduino D5  ── D   (D Flip-Flop)
Arduino D6  ── CLK (D Flip-Flop)
D-FF Q      ── Resistor (220Ω) ── LED1 Anode
D-FF Qbar   ── Resistor (220Ω) ── LED2 Anode
LED1 K, LED2 K ── GND

Example Code

void setup() {
  pinMode(5, OUTPUT);  // D
  pinMode(6, OUTPUT);  // CLK
}

void loop() {
  // Set D=HIGH, then pulse CLK → Q=HIGH, Qbar=LOW
  digitalWrite(5, HIGH);
  delay(100);
  digitalWrite(6, HIGH);  // Rising edge → Q captures D
  delay(500);
  digitalWrite(6, LOW);
  delay(1000);

  // Set D=LOW, then pulse CLK → Q=LOW, Qbar=HIGH
  digitalWrite(5, LOW);
  delay(100);
  digitalWrite(6, HIGH);  // Rising edge → Q captures D
  delay(500);
  digitalWrite(6, LOW);
  delay(1000);
}
Tip: The D Flip-Flop only updates on the rising edge of CLK. Changing D while CLK is steady has no effect on the output.
