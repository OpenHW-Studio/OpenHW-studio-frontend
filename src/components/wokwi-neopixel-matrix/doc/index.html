WS2812B RGB LED (NeoPixel)

Outputs

The WS2812B is an addressable RGB LED that integrates the LED and driver IC in a single package. Each pixel is individually controllable via a single-wire serial protocol. Multiple LEDs can be chained from a single data pin using the Adafruit NeoPixel library.

Pins

PinTypeDescription
DINDigitalData input — connect to Arduino digital pin (with 330–470 Ω inline resistor)
VCCPower5 V power supply
GNDPowerGround

Attributes

AttributeDefaultDescription
rows1Number of rows in the matrix
cols1Number of columns in the matrix

Wiring

Arduino D6 ──[ 470Ω ]── DIN (NeoPixel)
5V                   ── VCC (+ 100 µF capacitor to GND recommended)
GND                  ── GND

Example Code (Adafruit NeoPixel)

#include <Adafruit_NeoPixel.h>

#define PIN    6
#define NUMPIXELS 8

Adafruit_NeoPixel strip(NUMPIXELS, PIN, NEO_GRB + NEO_KHZ800);

void setup() {
  strip.begin();
  strip.setBrightness(50);  // 0–255
}

void loop() {
  for (int i = 0; i < NUMPIXELS; i++) {
    strip.setPixelColor(i, strip.Color(255, 0, 0));  // Red
    strip.show();
    delay(100);
  }
}
Tip: Use a 100–470 µF capacitor between VCC and GND close to the first LED to protect against power surges. Add a 300–500 Ω resistor on the DIN line.
