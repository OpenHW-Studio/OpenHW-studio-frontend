LED

Outputs

Light-emitting diode. Emits light when sufficient current flows from Anode (A) to Cathode (K). The color can be configured in the component attributes. Always use a current-limiting resistor (typically 220 Ω for 5 V) in series.

Pins

PinLabelTypeDescription
AAnodeInputPositive terminal (+). Connect through a resistor to a digital output pin.
KCathodeInputNegative terminal (–). Connect to GND.

Attributes

AttributeDefaultDescription
colorredLED color: red, green, blue, yellow, white, orange, purple

Wiring

Arduino Pin 13 ──[ 220Ω ]── A (LED) K ── GND

Example Code

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);  // LED on
  delay(500);
  digitalWrite(13, LOW);   // LED off
  delay(500);
}
Tip: Use analogWrite() on a PWM pin (3, 5, 6, 9, 10, 11) to control brightness.
