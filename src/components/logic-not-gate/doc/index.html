NOT Gate (Inverter)

Logic

A digital logic inverter that outputs the complement of its input. When the input is HIGH (≥ 2.5V), the output is LOW (0V), and when the input is LOW (< 2.5V), the output is HIGH (5V). Equivalent to a 7404 TTL inverter IC.

Truth Table

Input (IN) Output (OUT)
LOW (0) HIGH (1)
HIGH (1) LOW (0)

Pins

Pin Type Description
IN Digital Input signal
OUT Digital Inverted output signal

Wiring


Arduino D7  ── IN  (NOT Gate)
NOT Gate OUT ── Resistor (220Ω) ── LED Anode
LED Cathode ── GND

Example Code

#define INPUT_PIN 7

void setup() {
  pinMode(7, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(7, HIGH);
  Serial.println("IN=HIGH → OUT=LOW (LED OFF)");
  delay(3000);

  digitalWrite(7, LOW);
  Serial.println("IN=LOW → OUT=HIGH (LED ON)");
  delay(1000);
}
Tip: The NOT gate uses TTL logic levels. Input voltages ≥ 2.5V are treated as HIGH; below 2.5V as LOW. The output drives a full 5V when HIGH and 0V when LOW.
