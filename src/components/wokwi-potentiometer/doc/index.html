Rotary Potentiometer

Sensors

A rotary potentiometer (pot) is a variable resistor that outputs an analog voltage between 0 V and VCC proportional to the knob's rotation angle. Read it using analogRead() to get a value from 0 to 1023.

Pins

PinTypeDescription
1 (GND)PowerConnect to Arduino GND
2 (VCC)PowerConnect to Arduino 5 V or 3.3 V
SIGAnalogWiper output — connect to Arduino analog pin (A0–A5)

Attributes

AttributeDefaultDescription
value50Knob position as a percentage (0–100)

Wiring

Pot Pin 1 (GND) ── Arduino GND
Pot Pin 2 (VCC) ── Arduino 5V
Pot SIG         ── Arduino A0

Example Code

void setup() {
  Serial.begin(9600);
}

void loop() {
  int raw = analogRead(A0);          // 0–1023
  float voltage = raw * (5.0 / 1023.0);
  int percent = map(raw, 0, 1023, 0, 100);

  Serial.print("Raw: "); Serial.print(raw);
  Serial.print("  Voltage: "); Serial.print(voltage, 2);
  Serial.print(" V  Position: "); Serial.print(percent);
  Serial.println("%");
  delay(200);
}
Tip: During simulation, right-click the potentiometer and use the context menu slider to change the knob position in real time.
