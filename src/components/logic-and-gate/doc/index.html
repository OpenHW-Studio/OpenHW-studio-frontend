AND Gate

Logic

A 2-input digital AND gate. The output is HIGH only when both inputs are HIGH. Equivalent to a 7408 TTL AND gate IC.

Truth Table

Pins

PinTypeDescription
IN1DigitalInput 1
IN2DigitalInput 2
OUTDigitalOutput — HIGH when both inputs are HIGH

Wiring

Arduino D6  ── IN1 (AND Gate)
Arduino D7  ── IN2 (AND Gate)
AND Gate OUT ── Resistor (220Ω) ── LED Anode
LED Cathode ── GND

Example Code

void setup() {
  pinMode(6, OUTPUT);
  pinMode(7, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Both HIGH → LED ON
  digitalWrite(6, HIGH);
  digitalWrite(7, HIGH);
  Serial.println("IN1=1, IN2=1 → OUT=1");
  delay(1000);

  // One LOW → LED OFF
  digitalWrite(6, LOW);
  Serial.println("IN1=0, IN2=1 → OUT=0");
  delay(1000);
}
Tip: The AND gate uses TTL logic levels. Input voltages ≥ 2.5V are HIGH; below 2.5V are LOW.
