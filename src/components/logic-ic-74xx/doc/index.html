Universal 74xx Logic IC

Logic

A configurable 14-pin DIP IC that emulates any standard 74-series logic gate. Select the IC type via the right-click context menu, and the pinout and internal logic adjust automatically.

Pinout – Quad 2-Input NOR (7402) ⚠️ UNIQUE LAYOUT

Unlike other quad gates, the 7402 NOR gate outputs are on pins 1, 4, 10, and 13. You cannot just swap a 7408 for a 7402 without rewiring!

Wiring Example – AND Gate (7408)


Arduino 5V  ────► p14 (VCC)
Arduino GND ────► p7  (GND)

Arduino D2  ────► p1  (1A input)
Arduino D3  ────► p2  (1B input)

p3 (1Y output) ──► Resistor ──► LED ──► GND
Tip: The IC requires both VCC (pin 14) and GND (pin 7) to be connected. Without power, all outputs will be LOW regardless of inputs.
