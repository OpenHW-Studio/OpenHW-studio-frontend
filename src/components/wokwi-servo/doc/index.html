Servo Motor

Actuators

A hobby servo motor that provides precise angular position control from 0° to 180°. Position is controlled by the pulse width of a PWM signal. Use the Arduino Servo library for easy angle control.

Pins

PinTypeDescription
GNDPowerGround (usually brown wire)
V+Power5 V supply (usually red wire)
PWMDigitalPWM signal input (usually orange/yellow wire)

PWM Timing

Pulse WidthAngle
1.0 ms0°
1.5 ms90° (center)
2.0 ms180°

Wiring

Servo GND  ── Arduino GND
Servo V+   ── Arduino 5V
Servo PWM  ── Arduino D9

Example Code

#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);   // PWM pin 9
}

void loop() {
  myServo.write(0);    // Go to 0°
  delay(1000);
  myServo.write(90);   // Go to 90°
  delay(1000);
  myServo.write(180);  // Go to 180°
  delay(1000);
}
Tip: Right-click the servo on the canvas during simulation to manually set the angle via the context menu slider.
