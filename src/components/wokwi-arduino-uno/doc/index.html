Arduino Uno

Boards

The Arduino Uno is a microcontroller board based on the ATmega328P running at 16 MHz. It is the central processing unit of your simulation circuit — it runs the Arduino sketch (C/C++) and controls all peripherals via its digital, analog, and bus pins.

Minimal Blink Sketch

void setup() {
  pinMode(13, OUTPUT);  // Built-in LED
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
Tip: D13 is connected to the on-board LED. Use it for quick tests without any external components.
