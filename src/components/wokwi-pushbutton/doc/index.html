wokwi-pushbutton Reference

Inputs

OpenHW Studio component reference

A 12mm momentary tactile push button. When pressed, terminals 1 and 2 are connected (closed circuit). When released, they are disconnected (open circuit). Use a pull-down or pull-up resistor to avoid floating input levels.

Component IDwokwi-pushbutton Display LabelPush Button CategoryInputs Canvas Size34 x 34

Pins

PinTypeDescription
1digitalTerminal 1
2digitalTerminal 2

Attributes

AttributeDefaultDescription
colorblueVisual button cap color in the simulator.

Wiring (Active-HIGH with pull-down)

5V ----[ Button ]---- D2 (Arduino)
               |--[ 10k ohm ]-- GND

Wiring (Active-LOW with INPUT_PULLUP)

GND ----[ Button ]---- D2 (Arduino)
                     pinMode(2, INPUT_PULLUP)

Example Code

void setup() {
  pinMode(2, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(2) == LOW) {
    Serial.println("Pressed!");
  }
  delay(50);
}
Tip: In simulation, click the button while running to toggle the signal and observe input behavior immediately.
