Push Button

Basic

A momentary tactile push button. When pressed, terminals 1 and 2 are connected (closed circuit). When released, they are disconnected (open circuit). Use a pull-down or pull-up resistor to avoid floating input values on the Arduino pin.

Pins

PinTypeDescription
1PassiveTerminal 1
2PassiveTerminal 2

Wiring (Active-HIGH with pull-down)

5V ──[ Button ]──── D2 (Arduino)
                 └──[ 10kΩ ]── GND

Wiring (Active-LOW with internal pull-up)

GND ──[ Button ]──── D2 (Arduino)
                     (INPUT_PULLUP enabled in code)

Example Code (Active-LOW, internal pull-up)

void setup() {
  pinMode(2, INPUT_PULLUP);  // Internal 20–50 kΩ pull-up
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(2) == LOW) {   // Button pressed
    Serial.println("Pressed!");
  }
  delay(50);
}
Tip: During simulation, click the button on the canvas while the simulation is running to toggle its state.
