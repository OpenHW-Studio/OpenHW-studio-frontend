Resistor

Basic

A resistor is a passive two-terminal component that limits current flow by opposing electrical current. It is described by Ohm's Law: V = I × R. The resistance value is configurable via the context menu.

Pins

PinTypeDescription
p1PassiveTerminal 1 (polarity-independent)
p2PassiveTerminal 2

Attributes

AttributeDefaultDescription
value220Resistance in Ohms (Ω). Set via context menu.

Common Values

ValueUse Case
220 ΩCurrent-limiting for 5 V LED (≈14 mA)
330 ΩCurrent-limiting for 5 V LED (≈9.5 mA)
1 kΩPull-up / pull-down for digital inputs
10 kΩHigh-impedance pull-up for buttons/sensors

LED Current-Limiting Formula

R = (Vsupply – Vforward) / I_desired

Example (red LED at 5V, 20 mA):
R = (5V – 2V) / 0.02A = 150 Ω → use 220 Ω (next standard value)
Tip: Right-click the resistor on the canvas to open the context menu and change the resistance value in real time.
