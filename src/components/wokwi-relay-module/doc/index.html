Relay Module

Single-channel 5V relay module. Electrically isolates a high-voltage or high-current load from the Arduino. Default trigger is active LOW — the relay energises when the IN pin is pulled LOW.

5V Relay Module

The relay module acts as an electrically controlled switch. When the IN pin is pulled LOW, the coil energises and COM connects to the Normally Open (NO) terminal. When IN is HIGH, COM stays connected to Normally Closed (NC).

In OpenHW Studio, right-click the relay during simulation to toggle between Active LOW and Active HIGH trigger modes.

► Try it in the Simulator

Relay connected to Arduino pin 7. The relay toggles ON and OFF every 2 seconds. Watch the state indicator change on the component.

Example Code

const int RELAY_PIN = 7;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  // Active LOW: HIGH = relay OFF (safe default on startup)
  digitalWrite(RELAY_PIN, HIGH);
}

void loop() {
  digitalWrite(RELAY_PIN, LOW);   // Relay ON
  delay(2000);
  digitalWrite(RELAY_PIN, HIGH);  // Relay OFF
  delay(2000);
}
