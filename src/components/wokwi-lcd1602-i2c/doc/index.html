I2C LCD 16x2

Display

A 16-column by 2-row Liquid Crystal Display module equipped with an I2C backpack. It matches standard real-world I2C LCD modules and works natively with Arduino LiquidCrystal_I2C libraries.

Default Configuration

I2C Address0x27
Dimensions16 columns, 2 rows

Wiring with Arduino


Arduino 5V  ────► VCC
Arduino GND ────► GND
Arduino A4  ────► SDA
Arduino A5  ────► SCL

Example Code (Arduino)


#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Initialize the LCD at address 0x27, 16 cols, 2 rows
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0); // 0th col, 0th row
  lcd.print("OpenHW Studio!");
  
  lcd.setCursor(0, 1); // 0th col, 1st row
  lcd.print("Simulation OK");
}

void loop() {
  // Application loop
}
