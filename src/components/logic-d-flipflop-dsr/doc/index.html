D Flip-Flop (with Set/Reset)

Logic

A positive-edge-triggered D Flip-Flop with asynchronous active-HIGH Set and Reset pins. The Set and Reset pins have the highest priority and act immediately, ignoring the clock.

Note: If both R and S are HIGH simultaneously, R has priority in this implementation and Q becomes LOW.

Wiring


Arduino D4  ── S   (D-FF DSR)
Arduino D5  ── D   (D-FF DSR)
Arduino D6  ── CLK (D-FF DSR)
Arduino D7  ── R   (D-FF DSR)
D-FF Q      ── Resistor (220Ω) ── LED Anode
LED Cathode ── GND
Tip: When S and R are LOW, it acts exactly like a standard D Flip-Flop. Use the S and R pins to force the flip-flop to a known state asynchronously without waiting for a clock pulse.
