Buzzer

Outputs

A piezoelectric buzzer that generates audio tones when driven by a digital or PWM signal. The tone frequency (pitch) is determined by the frequency of the signal applied. Use the Arduino tone() function for easy frequency control.

Pins

PinTypeDescription
1DigitalPositive terminal — connect to Arduino digital/PWM pin
2PowerNegative terminal — connect to GND

Wiring

Arduino D8 ── Pin 1 (Buzzer) Pin 2 ── GND

Example Code — tone()

#define BUZZER_PIN 8

void setup() {}

void loop() {
  tone(BUZZER_PIN, 440);   // Play A4 (440 Hz)
  delay(500);
  tone(BUZZER_PIN, 880);   // Play A5 (880 Hz)
  delay(500);
  noTone(BUZZER_PIN);      // Silence
  delay(500);
}
