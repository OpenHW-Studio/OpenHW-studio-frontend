Linear (Slide) Potentiometer

Sensors

A linear slide potentiometer outputs a variable analog voltage as the slider moves along a linear track from one end (GND) to the other (VCC). Read with analogRead(). Commonly used for volume faders, position sensing, and HMI controls.

Pins

PinTypeDescription
VCCPower5 V supply
GNDPowerGround
SIGAnalogWiper — analog output proportional to slider position

Attributes

AttributeDefaultDescription
value50Slider position as a percentage (0 = GND end, 100 = VCC end)

Example Code

void setup() { Serial.begin(9600); }

void loop() {
  int raw = analogRead(A0);
  float pos = raw * 100.0 / 1023.0;  // 0–100%
  Serial.print("Position: ");
  Serial.print(pos, 1);
  Serial.println("%");
  delay(100);
}
Tip: During simulation, drag the slider handle left/right on the canvas (while running) or use the context menu to set the position numerically.
