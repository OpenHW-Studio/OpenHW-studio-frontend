L298N Motor Driver

Actuators

The L298N is a dual H-bridge motor driver IC that can independently control two DC motors (channels A and B). It supports motor voltages up to 46 V and up to 2 A per channel. Use the ENA/ENB pins for PWM speed control.

Pins

PinDescription
ENAEnable channel A (PWM for speed control of Motor A)
IN1, IN2Direction control for Motor A
IN3, IN4Direction control for Motor B
ENBEnable channel B (PWM for speed control of Motor B)
OUT1, OUT2Motor A output terminals
OUT3, OUT4Motor B output terminals
12VMotor power supply (up to 46 V)
GNDCommon ground
5VLogic 5 V output (can power Arduino if jumper set)

Truth Table (Motor A)

ENAIN1IN2Result
HIGH/PWMHIGHLOWForward
HIGH/PWMLOWHIGHReverse
ANYLOWLOWBrake
LOWANYANYStopped

Example Code

#define ENA 5   // PWM capable
#define IN1 6
#define IN2 7

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
}

void setMotorA(int speed) {             // -255 to +255
  if (speed >= 0) {
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
    analogWrite(ENA, speed);
  } else {
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, HIGH);
    analogWrite(ENA, -speed);
  }
}

void loop() {
  setMotorA(200);   // Forward 78% speed
  delay(2000);
  setMotorA(-200);  // Reverse 78% speed
  delay(2000);
}
Tip: Remove the ENA/ENB jumpers to use PWM speed control. Keep them in place to run the motors at full speed.
