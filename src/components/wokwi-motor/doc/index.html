DC Motor

Outputs

A DC motor that converts electrical energy into rotational mechanical motion. The direction of spin is determined by current polarity across its terminals. Requires an H-bridge motor driver (e.g., L298N) for safe operation from an Arduino — never connect directly to an Arduino pin.

Pins

PinTypeDescription
1PowerMotor terminal 1
2PowerMotor terminal 2

Direction Control

Pin 1Pin 2Result
HIGHLOWForward
LOWHIGHReverse
LOWLOWBrake (coast)

Example Wiring with L298N

Arduino D5 (PWM) ── L298N ENA
Arduino D6       ── L298N IN1
Arduino D7       ── L298N IN2
L298N OUT1       ── Motor Terminal 1
L298N OUT2       ── Motor Terminal 2

Example Code

#define ENA 5
#define IN1 6
#define IN2 7

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
}

void loop() {
  // Forward at 50% speed
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, 128);
  delay(2000);

  // Reverse at full speed
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, 255);
  delay(2000);
}
Tip: Add a flyback diode (1N4007) across motor terminals to protect against inductive voltage spikes in real hardware.
