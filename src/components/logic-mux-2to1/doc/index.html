MUX 2:1 (Multiplexer)

Logic

A 2-to-1 digital multiplexer. Routes one of two data inputs to the output based on the select line. When SEL is LOW, D0 is passed to OUT. When SEL is HIGH, D1 is passed to OUT.

Function Table

SEL OUT
0 D0
1 D1

Pins

Pin Type Description
D0 Digital Data input 0 (selected when SEL=LOW)
D1 Digital Data input 1 (selected when SEL=HIGH)
SEL Digital Select line — chooses which input to route
OUT Digital Output — passes the selected input

Wiring


Arduino D5  ── D0  (MUX)
Arduino D6  ── D1  (MUX)
Arduino D7  ── SEL (MUX)
MUX OUT ── Resistor (220Ω) ── LED Anode
LED Cathode ── GND

Example Code

void setup() {
  pinMode(5, OUTPUT);  // D0
  pinMode(6, OUTPUT);  // D1
  pinMode(7, OUTPUT);  // SEL
  Serial.begin(9600);
}

void loop() {
  // D0=HIGH, D1=LOW, SEL=LOW → OUT=HIGH (selects D0)
  digitalWrite(5, HIGH);
  digitalWrite(6, LOW);
  digitalWrite(7, LOW);
  Serial.println("SEL=0 → OUT=D0=HIGH");
  delay(1000);

  // D0=HIGH, D1=LOW, SEL=HIGH → OUT=LOW (selects D1)
  digitalWrite(7, HIGH);
  Serial.println("SEL=1 → OUT=D1=LOW");
  delay(1000);

  // D0=LOW, D1=HIGH, SEL=HIGH → OUT=HIGH (selects D1)
  digitalWrite(5, LOW);
  digitalWrite(6, HIGH);
  Serial.println("SEL=1 → OUT=D1=HIGH");
  delay(1000);
}
Tip: The MUX acts as a digitally controlled switch. Use the SEL line to choose which data input appears at the output.
